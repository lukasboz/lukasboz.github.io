Stem Separator

A local-first AI audio application that separates songs into vocals, drums, bass, and other instruments without sending music to a cloud processing service.

Role Full-Stack & ML Engineer
Type AI Audio Application
Stack Python, Demucs, Next.js, .NET 8

Overview

Stem Separator turns a mixed audio track into four independent WAV stems: vocals, drums, bass, and other instruments. It uses the Demucs htdemucs model locally, keeping source audio and generated files on the user's computer while still providing a polished workflow for processing, playback, and export.

System Design

A shared FastAPI backend handles audio validation, FFmpeg decoding, PyTorch inference, output generation, and cleanup. The model is loaded once and reused across requests, while an inference lock prevents competing jobs from exhausting CPU or GPU memory. Hardware selection automatically prefers CUDA, then Apple MPS, before falling back to CPU.

Two clients use the same local API. The Next.js browser client streams progress through Server-Sent Events and uses the Web Audio API for synchronized playback and custom mix export. The native .NET 8 WPF client automatically manages the packaged backend and adds drag-and-drop, per-stem controls, keyboard transport, individual exports, and karaoke mixes.

Key Features

  • Four-stem AI separation for vocals, drums, bass, and other instruments
  • Private, local-only processing with automatic temporary-file cleanup
  • CUDA, Apple MPS, and CPU execution selected from available hardware
  • Live processing status, percentage updates, preview mode, and cancellation
  • Synchronized multistem playback with seeking and per-stem mute controls
  • Individual WAV downloads and browser-side custom mix export
  • Next.js browser interface and self-contained Windows x64 application
