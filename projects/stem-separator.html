Stem Separator.

One track. Every layer.

Local-first AI audio separation. Turn a song into vocals, drums, bass, and instrument stems with a shared backend for the web and Windows.

ROLEFull-Stack & ML Engineer
TYPEAI audio application
BUILT WITHPython · Demucs · FastAPI
01

The idea

A great recording contains more than one thing worth listening to. Stem Separator turns a mixed audio track into four independent WAV stems: vocals, drums, bass, and other instruments. The Demucs htdemucs model runs locally, keeping source audio and generated files on the user's computer.

02

One backend, two experiences

A shared FastAPI backend handles audio validation, FFmpeg decoding, PyTorch inference, output generation, and cleanup. The model loads once and is reused across requests. An inference lock prevents competing jobs from exhausting memory, and hardware selection prefers CUDA, then Apple MPS, then CPU.

The Next.js browser client streams progress through Server-Sent Events and uses the Web Audio API for synchronized playback and custom mix export. A native .NET 8 WPF client manages the packaged backend and adds drag-and-drop, per-stem controls, keyboard transport, and karaoke mixes.

03

What it does.

  • Four independent audio stems, exported as WAV files
  • Private, local processing with temporary-file cleanup
  • Automatic CUDA, Apple MPS, and CPU selection
  • Live progress, preview mode, and cancellation
  • Synchronized playback, seeking, and per-stem mute controls
  • Browser-based custom mixes and a self-contained Windows application
